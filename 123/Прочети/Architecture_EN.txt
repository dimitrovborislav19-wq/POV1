1. What We Actually Analyzed

We analyzed an obfuscated .NET application in which the licensing logic is not located in a single place, but is split across several layers:

local licensing/state layer
startup/orchestration layer
remote HTTP licensing client
request/response pipeline
signature/integrity seam
runtime state and UI consumers

The main conclusion is that this is not a simple license check inside one method, but a multi-stage architecture.

5. Why It Was Difficult to Reach the “Body”

There were three reasons at the same time:

1. Obfuscation

The names are destroyed and you cannot naturally read the flow.

2. Async state machine compilation

The real logic is not in:

Asmy84GEo1V
urpyBRyGunV
JMjyBO4Y9Pe

but in generated types such as:

<GetLicenseInfoAsync>d__7
<ProcessResponseAsync>d__12
<IsSignatureValid>d__13
<ReadObjectFromResponseAsync>d__14

3. dnSpy navigation quirks

When you click MoveNext, dnSpy often sends you back to the wrapper method instead of opening the clean body of the state machine.

6. What We Learned Anyway

Even without conveniently opening every MoveNext, we already understood enough:

Confirmed:
